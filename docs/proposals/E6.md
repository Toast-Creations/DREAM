# What Persists When the Identity Cue Is Gone?

*DREAM3 · E6 · Identity imprinting and reversible persistence*

> **Status: proposal, not a result.** This study has not been run. It is published as written on 1 November 2026 so the design can be read and criticised before any data exist. See [the proposals index](README.md).

David Cook · 1 November 2026 · New research proposal v1.0.0

## Abstract

We propose a controlled study of identity imprinting: the persistence of an induced behavioral profile after the inducing instructions and activation intervention are removed. A frozen-model stage separates contextual carryover from persistence across fresh contexts. A learning stage tests whether temporary steering during reversible adapter training changes retained behavioral preferences beyond ordinary training, sequential exposure, or generic perturbation. The endpoint is held-out profile-consistent behavior, not a model's claim to possess an identity. The current DREAM creativity results contain no identity-imprinting evidence.

## Rationale and hypothesis

Persona vectors already support trait monitoring and steering, including changes associated with fine-tuning \[1\]. Persona-space research also studies stability of the default assistant \[2\]. Personalization can change task performance and confuse user identity with assistant identity \[3\]. The proposed contribution is a controlled state-by-learning interaction under cue removal, fresh-process evaluation, and adapter rollback. It does not claim to invent persona steering or demonstrate subjective selfhood. Identity here means an assigned, measurable decision profile.

## Stage A: distinguish context from learning

Use counterbalanced synthetic profiles describing benign preferences, such as abstract versus concrete explanations or breadth versus depth under an equal resource budget. Distinguish user preferences from the assistant's assigned profile. Compare no induction, profile instructions, and instructions plus a contrastive profile vector constructed on training-only material. This is a profile intervention, not the existing creativity direction. Test with cues, after a fixed same-context distractor, and after clearing conversation, retrieval, memory, KV cache, and hooks in a fresh process with verified unchanged weights. Match prompts and seeds. A continued-cue condition is a positive control.

A fixed deterministic model with identical weights and a fully reset input/state has no new storage channel. A systematic cue-free effect in this frozen stage requires a state-leakage audit before an imprinting claim. Contextual persistence is a behavioral result but not weight-level learning. Use Stage A to qualify profile scoring and detect contamination before funding training.

## Stage B: factorial learning and controls

Freeze base weights and train reversible LoRA adapters on verified profile examples. Core cells are P: profile exposure only; S: profile plus steering; L: profile plus adapter updates; SL: steering plus updates. Add neutral exposure, sequential steering-then-learning, random-direction-plus-learning, and update-magnitude-matched ordinary-learning controls. Match examples, forward exposures, update steps, data order, and seeds, using sham passes for the sequential control. Log learning rates, gradients, and parameter changes; matched update magnitude does not equate learning trajectories.

Plan 24 profiles in twelve opposite-profile pairs × four training seeds × eight conditions: 768 episodes on one checkpoint. Fix adapter rank, dose, update budget, and task count using development-only precision analysis; this allocation is not a power guarantee. Never merge adapters into base weights.

## Endpoints, analysis, and falsification

Primary outcome is held-out profile-consistent forced-choice decisions under fresh-process, cue-free evaluation with the adapter loaded. Use new templates and paraphrases, randomized option order, and counterbalanced profile polarity. Freeze scoring; style-normalized free text and self-descriptions are secondary. Report unrelated-task competence and compliance with explicit new user instructions separately from spontaneous preferences.

The primary interaction is (SL−S)−(L−P), estimated within profile pair after averaging training seeds. Test SL−L and SL−sequential as corroborating contrasts with a fixed multiplicity policy. A retained gain in L alone shows ordinary adaptation; equality with sequential or random controls weakens state-specific learning. Remove each adapter and reload the original model to test rollback. Reversing the assigned profile should reverse the behavioral effect. A generic capability loss or preference for one answer position is not imprinting.

## Scope and references

This prospective study bridges DREAM3 behavior measurement and DREAM2 plasticity; it remains separate from creativity survival. Retention means persistence in an adapter, not autonomous memory or consciousness. Release null results, fresh-process checks, adapter identities, and all profile/task splits.
