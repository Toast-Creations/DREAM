# Predict Before Scaling Up

*DREAM3 · E5 · A held-out larger-model forecast*

> **Status: proposal, not a result.** This study has not been run. It is published as written on 1 November 2026 so the design can be read and criticised before any data exist. See [the proposals index](README.md).

David Cook · 1 November 2026 · Research proposal v1.1.0

## Abstract

We propose a prospective forecast of steering's added useful-survival value on a larger checkpoint withheld from the observed scaling analysis. Three smaller same-family checkpoints provide separate gains over strong prompting and temperature sampling. Before inspecting larger-checkpoint outcomes, we will register fixed forecasting methods, point predictions, uncertainty scenarios, and a deterministic tuning procedure. A later test on shared and new tasks assesses that forecast. Current 7B/8B cross-family pilots cannot support it, and one held-out checkpoint cannot establish generally calibrated scaling predictions.

## Rationale and hypothesis

Prediction-loss scaling is not a law for creativity or intervention gains \[1\]. Other steering studies report decreasing efficacy with size \[2\]. E2 must therefore provide a genuine within-family ladder and a usable endpoint before extrapolation. The hypothesis is that a fixed size-trend forecast has smaller error at the held-out checkpoint than a no-trend forecast. This is a descriptive comparison at one new size, not a powered population test over future models. A forecast near zero can be accurate without supporting deployment.

## Information boundary and design

Reserve one larger same-family checkpoint before any efficacy inspection. Keep it out of developer selection, direction comparisons, prompt tuning, and E3. Freeze a deterministic model-specific vector-construction and setting-selection rule. If a separate operator must calibrate the larger checkpoint, restrict that work to a sealed development pool under a fixed search budget; report this as forecasting the complete adaptation procedure, rather than zero-shot transfer. The forecasting analyst sees no calibration or evaluation outcomes until registration.

The planning evaluation contains 24 shared anchor tasks and 24 new sealed tasks × three seeds × four arms: 576 chains. Use E1's common developer, matched development, qualified endpoint, failure handling, and resource reporting. Register task identities and hashes before fitting forecasts. Anchor tasks test extrapolation in model size; new tasks test the additional shift in task content. Disclose E1/E2 data reuse rather than counting it as independent replication.

## Forecast and verification

For C−A and C−B separately, specify a linear model of gain against log parameter count using the three observed sizes. The comparator carries forward the gain at the largest observed checkpoint. Freeze both methods before seeing E2's size trend. Register parameter count, point forecasts, the provisional worthwhile gain of 0.5 qualifying ideas, analysis code, and timestamps before revealing the held-out result. Predeclare flat and saturating extrapolations as sensitivity scenarios, without selecting the most favorable curve after inspection.

With three observed checkpoints, curve uncertainty is poorly identified. Report task-sampling intervals conditional on each curve separately from uncertainty across plausible curve shapes. Do not label a task bootstrap as a fully calibrated prediction interval for a new model. If a combined predictive interval is supplied, its model-discrepancy assumptions must be explicit. Average seeds within tasks and retain task pairing across conditions and sizes.

After revelation, report signed and absolute forecast errors, comparison with the flat forecast, and inclusion in each registered interval/scenario, separately for anchor and new tasks. Report the actual held-out efficacy contrasts with simultaneous task-level uncertainty. One checkpoint supplies one extrapolation case; tasks do not multiply the number of held-out model sizes. Do not refit the curve and count its retrospectively improved prediction as prospective success.

## Decision and contribution

Claim useful larger-model added value only if the held-out experiment independently supports improvement over both effectiveness controls, with precision relative to the worthwhile effect. Accurate forecasting and positive effectiveness are separate outcomes. A benefit limited to anchor tasks constrains generalization. Additional held-out sizes and model families are distinct replications. Publish the original forecast and failed predictions, along with every tuning evaluation and resource cost. This study follows E2; it is not a reason to assume larger models will rescue an unresolved small-model result.
